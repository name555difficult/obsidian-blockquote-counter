# Changelog

## 1.0.2

- Remove unnecessary CSS priority overrides for hidden and printed badges.
- Include a package lockfile for automated build verification.
- Link to the official community directory in the installation instructions.

## 1.0.1

- Preserve custom view positions during plugin reloads.
- Safely handle deferred sidebar views during startup.
- Use the originating window's clipboard for copy actions in pop-out windows.
- Align the settings panel with Obsidian UI guidelines.
- Add the MIT license.

## 1.0.0

- Count top-level blockquotes and callouts independently.
- Show character badges in Live Preview, Source mode, and Reading view.
- Keep callout counts visible in the title bar when folded.
- Add a sidebar with character budgets, text previews, copy actions, and source navigation.
- Support UTF-16 and Unicode code-point counting, with auxiliary word and whitespace-free counts.
- Provide configurable character limits, warning thresholds, and badge visibility.
