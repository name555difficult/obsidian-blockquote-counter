# Blockquote Counter · 引用块统计

[English](README.md)

在 Obsidian 中分别统计每个顶层引用框和 callout 的正文字符数。写作时直接查看用量，按可调整的上限控制篇幅，并复制与计数一致的正文。

## 功能

- 在实时预览、源码模式和阅读视图中显示字符数。
- callout 的计数显示在标题栏，折叠正文后仍然可见。
- 侧栏为每个引用块显示独立卡片，包含剩余字符、进度条和正文预览。
- 一键复制正文，或定位到对应源码。
- 支持 UTF-16 和 Unicode 码点两种口径，另有按空白分隔的词数与去空白字符数。
- 默认上限 **2,000 字符**，可自行调整；达到 **90%** 时预警，超过上限时标红。

## 安装

1. 从[最新版本](https://github.com/name555difficult/obsidian-blockquote-counter/releases/latest)下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 在笔记库中创建 `.obsidian/plugins/blockquote-counter/`，把这三个文件放进去。
3. 重新加载 Obsidian，在 **设置 → 第三方插件**中启用 **Blockquote Counter**。

目前采用手动安装方式，插件尚未列入 Obsidian 第三方插件目录。

## 使用

将每段需要独立统计的文字放进一个顶层引用框。引用框前的标题会作为侧栏中的名称。

```markdown
## 写作摘录

> 这里是第一段文字。
>
> 这一段与上一段属于同一个统计块。

## 旅行清单

> [!note] 随身物品
> - 笔记本
> - 水杯
```

**同一引用框内部的空行也要保留 `>`。** 不带 `>` 的空白行会结束当前统计块，后面的引用框将单独计数。`note`、`tip`、`quote` 等 callout 类型采用相同规则。

在命令面板执行 **Blockquote Counter: 打开引用块统计**，或点击侧边功能区图标、状态栏，即可打开统计面板。使用 **复制正文**取得被计数的 Markdown 正文，使用 **定位**跳到对应位置。编辑模式下，还可运行 **复制光标所在引用块正文**命令。

[example.md](example.md) 提供可以直接在 Obsidian 中打开的示例。

## 计数规则

插件统计的是 **Markdown 正文源码**。复制操作和计数使用同一份文本。

| 内容 | 处理方式 |
| --- | --- |
| 每行最外层 `>` 和紧随其后的至多一个空格或制表符 | 去掉 |
| callout 首行标记及标题，例如 `[!note] 随身物品` | 去掉 |
| 引用框外的标题和文字 | 不计入 |
| 正文中的空格、制表符、换行和行尾空格 | 计入 |
| Markdown 标记、链接语法和公式源码 | 计入 |
| 嵌套引用标记及嵌套 callout 文字 | 归入最外层正文，不单独计数 |

`CRLF` 和 `CR` 换行会统一为 `LF`，每个换行计为一个字符。插件不额外添加末尾换行，也不删除正文首尾空白；显式写出的末尾空白引用行会保留。

默认 **UTF-16** 口径下，一般字母和常用中文各计 1，多数 emoji 计 2。切换为 **Unicode 码点**后，这些 emoji 计 1，但组合 emoji 和组合附加符号仍可能包含多个码点。两种口径都不等同于视觉上的字形数。当结果不同时，侧栏会同时显示两种数字。

词数按空白分隔，仅作为英文等语言的粗略辅助统计，不是中文分词。去空白字符数始终采用 UTF-16，不替代当前选定的字符预算。

## 适用范围

支持顶层 `>` 引用块及普通段落中省略 `>` 的续行。为了让边界清晰，建议引用框内每行都显式加上 `>`。

外层 YAML 属性、代码围栏中的示例和独立的外层注释块不参与统计。明确写在引用框正文内的注释源码仍会保留并计入。列表容器中的引用、特殊的 HTML 与 Markdown 混合嵌套不在完整解析范围内。

如果正文刚发生变化、侧栏尚未刷新就点击复制，插件会先刷新并提示再次点击，避免复制旧文本。

## 设置

在 **设置 → Blockquote Counter** 中可调整字符上限、预警比例、字符计数口径，以及是否显示框内计数。

## 隐私

插件在本地运行，不发起网络请求，不改写笔记，也不保存笔记正文。它只保存自身设置，并在你主动执行复制操作时，把所选引用块正文写入剪贴板。

## 开发

使用 Node.js 18 或更新版本，无需安装额外依赖即可构建和运行单元测试。运行时接口由 Obsidian 提供。

```sh
npm test
npm run check
npm run build
```

修改 `src/main.js` 和 `lib/counter.js` 后重新构建，将生成的 `main.js`、`manifest.json` 与 `styles.css` 安装到测试笔记库。

参考：[Obsidian 开发文档](https://docs.obsidian.md/Plugins/Getting+started/Build+a+plugin)、[Obsidian 官方 API](https://github.com/obsidianmd/obsidian-api)。
